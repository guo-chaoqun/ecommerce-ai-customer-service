# baseline_v2_v44 · V2 复评基线（v4.4 裁判统一口径）

本目录有两类输出，注意区分：

| 文件 | 角色 |
|---|---|
| `eval_results_baseline_v2.json` | V2 **原始**评测输出（旧裁判口径）。保留它是因为复评需要逐字复用其中的 `actual_response`（505/505 条与复评版完全一致），属于复评的输入留档 |
| `baseline_v2_v44.json` | **复评结果**：对同一批 V2 原始回复，用 v4.4 裁判（行为特征判定法）+ 修正用例重新打分。复评基线：通过率 476/505 = 94.3%，幻觉率 42/505 = 8.3% |

为什么要复评：旧裁判与 v4.4 裁判口径不同，直接拿旧分数和 V3 相比会产生评测污染（详见根 README「复评基准」）。

McNemar 配对检验（本目录 vs `../baseline_v3_full/`）：运行 `python analysis/09_mcnemar_test.py`，输出 b=23、c=9、精确双侧 p=0.0201。
