## 使用说明

### Dify 知识库配置建议
- 检索模式：混合检索（向量 + 关键词）
- TopK：15
- Rerank：启用（bge-reranker-v2-m3）
- Rerank TopK：5
- Score Threshold：0.3（先跑几轮再调）

### 客服话术优先级
1. 先核实订单号
2. 再判断问题类型（退货/换货/质保/错发/质量问题）
3. 引用对应规则文档中的话术要点
4. 用区间表达时效，不承诺具体日期

### 更新机制
- 业务政策变更 → 修改对应文档 → 版本号 +1
- 每月定期 review 有效性
- 过期文档标记 `deprecated: true`，不删除（保留历史追溯）
